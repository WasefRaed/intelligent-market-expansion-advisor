# AI Tool Usage Disclosure

The project was developed **with AI assistance**. This disclosure is intended for a submission reviewer and should be checked by the submitting developer before publication.

## Tools and how they were used

- **ChatGPT (OpenAI):** assisted with solution planning, architecture suggestions, Python/Agno and Streamlit implementation drafts, iterative debugging, test design, project documentation, financial and evidence safeguards, evaluation summaries. The human developer ran the software and shared the resulting tests, screenshots and logs for analysis.
- **Google Gemini API (via Agno):** provides the application's language-model reasoning, specialist-team coordination and executive-style narrative recommendations when a live AI request is made. Gemini is **not** the source of truth for the deterministic finance, location-screening, or official-reference registry datasets.
- **Agno:** primary agentic framework for the coordinator, domain specialists, and their Python tool integrations. Agno itself is a framework, not an additional evidence source.
- **Streamlit:** front-end dashboard and interactive scenario controls; not an AI model.

## Human verification and accountability

The developer manually tested ten business-question scenarios, inspected the source/evidence presentation, ran the offline Python tests, and captured a real team delegation log. On 2026-10-10, the Windows project reported **72 passing offline tests** and the Streamlit app launched. These checks validate specific engineering behavior, **not** the business truth of generated recommendations.

## Limits and responsible use

The snapshot includes hypothetical price bands, heuristic area scores, and research leads. These are not sourced commercial rent quotations, measured demand, local restaurant sales, or established returns. Official-page reference notes have restricted supported claims. Live search is disabled by default. The system is a research and planning aid; human review and independently collected market, property and regulatory evidence are necessary before an investment decision.

The developer retains responsibility for checking the final repository, code, documentation, permissions, license attribution, and all claims included in the submitted video.
